# AI Study Planner & Quiz Generator

A beginner-friendly educational mini project for creating a simple study schedule and practising a sample quiz.

## Features

- Enter subjects and daily study hours to create a balanced study plan.
- Add exam date and topics that need extra revision.
- Generate a sample multiple-choice quiz.
- Check quiz answers and get an instant score.
- Responsive layout for mobile and desktop.
- Runs entirely in the browser; no account, backend, or API key is required.

## Technology Stack

- HTML5
- CSS3
- JavaScript

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No installation is required.

## Publish with GitHub Pages

1. Create a repository on GitHub, for example `ai-study-planner-quiz-generator`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your website. The URL will be shown in the Pages settings.

## How it works

The planner divides the user's available study time across the subjects they enter and suggests time for breaks. The quiz section uses a set of sample questions and scores the selected answers.

## Important note

This is an educational prototype. Although the project demonstrates an AI-inspired personalized planning workflow, this version does **not** connect to a live AI model. The study plan is created with simple rules, and quiz questions are predefined examples. A future version could connect to an AI API through a secure backend. Never expose private API keys in browser-side JavaScript or commit them to GitHub.
